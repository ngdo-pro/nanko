# Skill : new-pdr

Utilisez ce skill pour documenter une décision produit (`/new-pdr [sujet]`).

## Procédure

1. Déterminer le prochain ID (`PDR-XXX`) dans `.specs/decisions/product/`.
2. Utiliser le template `.specs/templates/PDR_TEMPLATE.md`.
3. Consigner le problème, les options envisagées, la décision et les justifications (le « Why » et concessions UX).
4. Créer le document dans `.specs/decisions/product/PDR-XXX-[slug].md`.
